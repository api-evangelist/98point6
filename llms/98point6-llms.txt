# 98point6 Technologies

> 98point6 Technologies is a Seattle-based digital health software company, founded in 2015,
> that builds and licenses a cloud-based virtual care platform to health systems, payers and
> virtual care providers. Since selling its own care-delivery division in 2023 it operates
> purely as a licensed software provider. The platform pairs an AI-driven Automated Assistant
> for patient intake and visit documentation with a web-based Clinician Console carrying
> automated clinical decision support, plus a white-labeled patient application covering both
> asynchronous and real-time (messaging, audio, video) care.

## API surface

98point6 Technologies publishes **no public API**. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL specification, no SDK download and no self-serve
sign-up on any public 98point6 host. The subdomains `developer.98point6.com`,
`docs.98point6.com`, `api.98point6.com` and `app.98point6.com` do not resolve in DNS, and the
entire marketing site is fifteen pages.

An integration surface does exist — the platform page advertises HL7 and FHIR based EMR
integration with Epic and Cerner, SSO for patient login, and an SDK for building a fully
branded patient experience — but it is delivered to licensees under a commercial agreement.
The only public route to it is the demo-request form.
